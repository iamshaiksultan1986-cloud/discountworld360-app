# DISCOUNTWORLD360 PWA starter

This is a free, static PWA starter for GitHub Pages. It provides a branded installable app shell and an Open Website link to:
https://discountworld360.blogspot.com/

## Publish with GitHub Pages
1. Sign in to https://github.com/ and create a new **public** repository named `discountworld360-app`.
2. Upload all files and folders from this package. Keep `index.html`, `manifest.webmanifest`, and `sw.js` in the repository root; keep both PNGs inside `icons/`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish. Your app URL will normally be:
   https://YOUR-GITHUB-USERNAME.github.io/discountworld360-app/
7. Open that HTTPS URL in Chrome or Edge. Use the install icon in the address bar or the page's Install App button when it appears.

## Install
- Windows: open the app URL in Chrome/Edge and choose Install.
- Android: open the app URL in Chrome, tap the three-dot menu, then **Install app** or **Add to Home screen**.

## Important
This starter is an installable app launcher. The Open Website button opens the Blogger site in a separate browser tab. This avoids embedding problems that can occur when a Blogger site is placed inside another site's iframe. The latest Blogger content requires internet access. The app shell itself can load offline after its first successful visit.
